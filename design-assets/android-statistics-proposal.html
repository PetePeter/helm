What the supplied log proves

Statistics requests later received successful replies. The log records request names and byte counts, not the selected view or returned token rows.

It therefore does not confirm why token rows were missing at the time you noticed it.

Current code clue

The Android parser reads sheet.rows[].tokens. The screen then hides CLI rows whose total is zero for the selected period. The existing parser test covers nonzero token rows, but the supplied log cannot tell whether the reply contained zero values.

Proposed layout

Tokens: keep the CLI label and color marker fixed; scroll the period and Total columns as one aligned strip.

Timesheet: use the same fixed-label and scrollable-metrics pattern, with wider cells and small consistent gaps.

Both: apply subtle alternating A/B row backgrounds; keep totals visually distinct.

Approval gate

This is a design proposal only. After approval, implement the Android table layout, add focused Compose coverage, build the debug APK, then verify on-device if the handset is available.
